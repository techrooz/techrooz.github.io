فایل تنظیمات Claude Code در برخی پکیج‌های npm اطلاعات ورود را فاش کرده است

۱۷ آبان ۱۴۰۵ · ۱۰:۰۰
پژوهشگران Check Point گزارش داده‌اند که دست‌کم ۳۳ پکیج npm، فایل .claude/settings.local.json را همراه بسته‌ی منتشرشده در رجیستری عمومی قرار داده بودند. این فایل را Claude Code برای ذخیره‌ی دستورهای تأییدشده‌ی کاربر می‌سازد و در برخی موارد، اطلاعات ورود نیز درون همان دستورها ثبت شده بود.

چرا مهمه؟
پکیج‌های npm عمومی‌اند؛ هر کسی می‌تواند محتوای آن‌ها را دانلود و بررسی کند. اگر فایلی حاوی رمز یا کلید دسترسی ناخواسته منتشر شود، مهاجم می‌تواند بدون هیچ نفوذی از آن استفاده کند.

راه‌های پیشگیری ساده است: این فایل را به .gitignore و .npmignore اضافه کنید، پیش از انتشار با دستور npm pack --dry-run فهرست فایل‌های بسته را ببینید و رمزها را به‌جای نوشتن داخل دستور، از طریق متغیر محیطی در اختیار برنامه قرار دهید.

جمع‌بندی
ابزارهای هوش مصنوعی سرعت کار را بالا می‌برند، اما بررسی محتوای منتشرشده همچنان مسئولیت توسعه‌دهنده است.
